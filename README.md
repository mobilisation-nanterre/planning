# Planning d'occupation des salles

Copie publique, en lecture seule, du planning d'occupation des salles dans le cadre de la mobilisation à l'Université Paris Nanterre.

Les réservations sont saisies dans la page de gestion, réservée aux personnes autorisées. Cette copie est régénérée automatiquement environ toutes les heures : l'heure de la dernière mise à jour est affichée en haut de la page.

- `index.html` : la page publique (générée, ne pas modifier à la main).
- `outils/modele.html` : le modèle de la page.
- `outils/construire.py` : fabrique `index.html` à partir d'un export des salles et des réservations.
